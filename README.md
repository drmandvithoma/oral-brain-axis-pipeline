# The Oral-Brain Axis: Multi-Layer Data Warehouse Pipeline & Spatial Disparities

An enterprise SQL data warehouse architecture and geospatial epidemiological pipeline integrating socioeconomic deprivation matrices with localized public health indicators across the United States.

## 📌 Project Overview
This repository contains the full analytical data engineering pipeline used to model the co-occurrence of adult tooth loss, healthcare access gaps, functional cognitive disability, and mental distress at a national scale. The project addresses the **geospatial linkage mismatch problem** by building a reproducible bridging schema between distinct administrative boundaries.
