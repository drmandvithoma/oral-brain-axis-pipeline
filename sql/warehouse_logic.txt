The pipeline (Figure 1) follows a three-layer design. In the staging layer, files were loaded unchanged with every identifier typed as text, because integer typing silently removes the leading zero of FIPS codes for states 01–09 and breaks joins. The integration layer standardized block group FIPS to 12 characters (state 2 + county 3 + tract 6 + block group 1), derived state, county and tract keys by substring, retained GISJOIN as a parallel key, converted ADI ranks to numeric and recoded suppression codes to missing. The analytical layer holds a star schema (geography and measure dimensions; ADI and PLACES fact tables) from which an analysis mart was produced. Data-quality contracts were evaluated at each load: uniqueness of block group FIPS, key length, value domain (ADI rank 1–100), expected row counts, and match rates between sources
